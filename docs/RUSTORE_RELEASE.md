# Публикация «Дарик» 1.0 в RuStore

## Формат первой версии

Для первого выпуска используем подписанный универсальный APK. Это проще AAB:
RuStore принимает APK, а отдельная передача ключей через PEPK не требуется.

Пакет: `ru.maxx52.daric`  
Версия: `1.0`  
Код версии: `1`  
Минимальная версия: Android 9 (API 28)  
Категория: «Полезные инструменты»  
Рекомендуемое возрастное ограничение: 12+ из-за внешнего каталога GIF.

## 1. Создание ключа подписи

В Android Studio откройте **Build → Generate Signed Bundle / APK → APK → Create new**.

Рекомендуемые параметры:

- файл: `daric-release.jks`;
- alias: `daric`;
- срок действия: не менее 25 лет;
- надёжные разные пароли хранилища и ключа.

Сохраните минимум две резервные копии JKS и паролей в защищённых местах.
Без исходного ключа Android не позволит выпускать обновления с тем же пакетом.

## 2. Настройка локальной сборки

Скопируйте `keystore.properties.example` в `keystore.properties` и заполните:

```properties
storeFile=C:/secure/daric-release.jks
storePassword=...
keyAlias=daric
keyPassword=...
```

В `local.properties` должен находиться рабочий production-ключ KLIPY:

```properties
KLIPY_API_KEY=...
```

Оба файла с секретами исключены из Git.

## 3. Сборка APK

В PowerShell из корня проекта:

```powershell
.\gradlew.bat clean assembleRelease
```

Готовый файл:

```text
app\build\outputs\apk\release\app-release.apk
```

Сборка остановится с понятной ошибкой, если подпись или KLIPY API-ключ не настроены.

Перед загрузкой установите APK на реальный телефон и проверьте:

1. включение и выбор клавиатуры;
2. русскую и английскую раскладки;
3. цифровой ряд, удаление при удержании и подсказки;
4. эмодзи, открытки и GIF;
5. светлую/тёмную тему и все варианты фона;
6. очистку персональной истории.

## 4. Карточка RuStore

Название — не более 30 символов:

> Дарик — клавиатура

Краткое описание — не более 80 символов:

> Русская клавиатура с подсказками, GIF, открытками, эмодзи и темами.

Подробное описание:

> «Дарик» — удобная клавиатура для тёплого и живого общения.
>
> Печатайте на русском и английском, используйте отдельный цифровой ряд и выбирайте
> подходящие слова из строки подсказок. Персональные подсказки обучаются только на
> устройстве, их можно отключить или полностью очистить.
>
> Добавляйте эмодзи, находите GIF и отправляйте готовые открытки прямо из клавиатуры.
> Настройте высоту клавиш, вибрацию, звук, светлый или тёмный режим. Выберите одну из
> шести цветовых тем: «Лаванда», «Океан», «Роза», «Лес», «Закат» или «Графит» —
> с однотонным либо градиентным фоном.
>
> Набираемый текст не передаётся разработчику. Интернет используется только для GIF.

Что нового:

> Первый выпуск «Дарик»: две раскладки, подсказки, цифровой ряд, эмодзи, GIF,
> открытки, персональное обучение и шесть цветовых тем.

## 5. Медиафайлы

- иконка: `store-assets/daric-icon-512.png` — 512×512, PNG, с заполненным фоном;
- минимум три настоящих скриншота телефона;
- ориентация всех скриншотов должна совпадать;
- допустимо 320–3840 px по стороне, PNG/JPG, до 5 МБ каждый.

Рекомендуемые кадры:

1. клавиатура с цифровым рядом и подсказками;
2. панель GIF или открыток;
3. экран настроек с цветными темами.

Не используйте макеты вместо фактических скриншотов работающего приложения.

## 6. Загрузка

В RuStore Консоли выберите **Приложения → Добавить приложение → Универсальное →
Бесплатное**, создайте «Дарик — клавиатура» и загрузите подписанный
`app-release.apk`. После обработки заполните карточку, добавьте иконку и три
скриншота, затем отправьте версию на модерацию.
